# Independent audit assignment

**For the XI Forever Offline developers’ AI**

Audit VanaSync from the attached package. Reproduce the simulator with a disposable catalog. Evaluate the proposed native contract against approved sources and a pinned isolated build.

| Area | Questions and evidence |
| --- | --- |
| Compatibility | Which documented extension points support each snapshot field and BGM operation? Which builds and states are unsupported? |
| State and audio | Reproduce composition changes, grace, rapid re-entry, stale events, fade cancellation, decoder failures and album resume. |
| Restoration | Reproduce timeout, bridge and renderer loss, protected scenes, native recovery and uninstall. Look for stuck mute and duplicate playback. |
| Data integrity | Verify hashes, order, stable IDs, Unicode filenames, persistent preferences and rollback. |
| Security and privacy | Review local protocol and filesystem boundaries, base path handling, IPC provenance, telemetry, dependencies and log contents. |
| Performance | Record environment, timing, memory, CPU and media handles before and during sustained playback. |
| Distribution | Verify audio provenance and confirm permissions for any proposed redistribution. |

Return severity, component, exact build, reproduction, source evidence, expected/observed behavior and remediation for every finding. Label evidence **confirmed**, **falsified**, **unverified** or **unsupported**. Give simulator and native go/no-go decisions separately. Use explicit project permission for private repo or live environment access.

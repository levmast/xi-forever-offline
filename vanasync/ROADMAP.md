# Roadmap

| Stage | Scope and gate |
| --- | --- |
| 0.1.0 Battle Resonance | Simulator, three battle mixes, fallback, album transport and isolated QA |
| Native battle preview | Pin a supported XI Forever Offline build. Verify combat snapshots, renewable BGM-only ownership and rollback before live trial. |
| Native playback release | Verify cutscenes, SFX, add-on coexistence and performance. Add approved timing data and album metadata. |
| Zone music | Add per-zone playlists and per-track choices, shuffle/repeat/skip, Custom and Ambience Only modes. Use the actual delivered asset inventory. |
| Environmental ambience | Split zone, battle and ambience audio. Add authorized weather and day/night environmental sounds. |
| Tooling and presentation | Pack management, VanaStudio, OBS now playing, verified YouTube album/artist links and approved launcher integration. |

Start zone expansion after battle acceptance. Add alternate musical arrangements only when the creators deliver them.
